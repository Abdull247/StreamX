# StreamX Frontend

React + Vite frontend for the StreamX multi-site video API.

- **Stack:** React 18, react-router-dom, Vite 5, plain CSS (CSS variables, no framework)
- **Setup:** `cp .env.example .env.development` → set `VITE_API_BASE_URL` → `npm install && npm run dev`
- **Env:** `VITE_API_BASE_URL` = backend base URL (default `http://localhost:3001`)

See [`info.md`](./info.md) for the full feature + layout documentation.
